## Mason v0.2.0

本轮重点改进拼版导入、开孔核对和配置预设，并新增日语、韩语及跟随系统语言。

### 拼版与开孔

- **混合拼版**：支持识别不同板子组成的拼版，选择整版或具体子板；优化选板预览和高亮交互。
- **测试点过滤**：结合 Gerber 用途属性、可选的飞针测试信息和几何特征识别测试点，减少元件焊盘被误过滤的情况。
- **二维核对与手动开孔**：对比原始焊盘、实际开孔和叠加结果；在原始焊盘中左键点选或框选，批量开孔、封孔或恢复自动判断。右键拖动，滚轮缩放，支持撤销重做和首次使用引导。
- **整版与子板同步**：手动开孔选择随整版和子板切换保持同步。

### 参数与装配

- **预设交互**：默认配置和自定义配置均可另存为新预设；自定义预设支持保存修改、重命名和删除，切换时可处理未保存的修改。
- **预设范围**：仅保存打印与结构参数，不包含 PCB 尺寸、厚度或 Gerber 数据；重启后恢复上次选中的已保存预设。
- **夹持区域预览**：凸台与唇宽调整移至常用参数，并提供平面夹持区域预览。
- **紧固件参考**：显示装配所需螺丝、螺母的建议规格、长度和数量。
- **打印装配余量**：定位柱配合孔默认单边间隙调整为 0.225 mm，B 面螺母孔增加打印余量。
- **导出与退出提醒**：导出前提醒核对尚未确认的钢网尺寸；存在未导出的修改时，关闭软件或更新重启前进行确认。

### 界面与语言

- **四种界面语言**：支持简体中文、英语、日语、韩语，可手动选择或跟随系统；保留已有手动语言选择。
- **字体与弹窗**：统一字体和确认弹窗样式，修正多层弹窗及语言菜单的显示层级，改善日语和韩语字体适配。
- **简化工作流程**：移除项目文件保存、加载及工作草稿恢复功能；常用制造参数通过配置预设复用。
- **README**：保留原版结构与内容，仅更新功能变动，并提供日语和韩语版本。

### 稳定性

- 修复退出确认后无法关闭窗口的问题：补齐窗口关闭权限，确认后直接关闭，取消后仍可继续工作。
- 改进模型生成、缓存和预览加载，降低重复操作的等待。
- 构建时核对 Python 引擎源文件与打包副本，防止安装版携带旧版建模逻辑。

### 更新方式

已安装支持自动更新的版本，可在「设置 → 关于」检查更新并下载安装。也可从发布页下载对应平台的安装包。
