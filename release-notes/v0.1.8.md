## Mason v0.1.8

### Improvements

- Faster startup and first render: register only the Element Plus components used by Mason and remove unused global icon registration. The production JavaScript bundle is about 40% smaller when compressed.
- Prioritize the visible model after Gerber import, then preload other parts one at a time. Refresh keeps the current preview visible until the replacement is ready.

### Fixes

- Recalculate print volume and weight when parameters change; allow retry after failures and ignore stale results.
- Preserve and release cached STL geometry correctly across preloading, refreshes, parameter changes, and component teardown.
- Include both paste sides when estimating board bounds if the Gerber archive has no usable outline.
- Clear pads left over from a previous project when importing an outline-only board.
- Preserve image-level Gerber polarity in CAD inputs and geometry cache validation.
