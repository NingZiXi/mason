## Mason v0.1.7

### Features

- **In-app updates**: installed releases check for updates at startup. The About page shows release notes and lets you confirm, download, and install a signed update, then restart the app.
- Release builds now publish signed updater artifacts and the `latest.json` manifest for Windows, Apple Silicon macOS, and Linux AppImage.

### Fixes and improvements

- Project files now retain the full set of application parameters when saved and restored.
- Improved release validation and build reliability for the bundled Python engine and Rust backend.
