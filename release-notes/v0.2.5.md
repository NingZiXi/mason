## Mason v0.2.5

本轮主要改善双面刷锡入口、二维开孔编辑和预览交互，并加强 macOS 安装包检查。

### 编辑与预览

- 双面刷锡改为更醒目的整块入口，开启状态更清楚。
- 二维开孔核对支持连续编辑：手动开孔、封孔或恢复自动判断后立即显示，后台重算期间仍可继续操作。
- 重算中的旧开孔结果会淡化，过期统计暂不显示；后台失败可重试，不打断原始焊盘编辑。
- 避空编辑画布为选中区域显示深度或「贯穿」，以同主题明暗区分深度，批量修改后轻量强调实际变化的区域。
- 改善微小避空区的标签、放大后的离屏显示及撤销时的反馈清理。

### 界面体验

- 改善 3D 部件与装配切换时的取景过渡，拖动视图可立即接管相机。
- 钢网夹与 PCB 钢网分别记住侧栏滚动位置和高级参数展开状态。
- 修复自定义钢网厚度输入被重置的问题，保留当前输入值。
- 统一常用按钮与工具的提示样式，支持键盘聚焦和 Esc 关闭；提示自动避开窗口边缘，背景提示不会覆盖新打开的弹窗。
- 优化更新状态、下载进度和更新说明的显示，较长说明可按需展开。

### macOS 安装

- 为 Apple Silicon 安装包加入临时应用签名及应用、自动更新包和 DMG 完整性检查。
- 避免内置 Python 引擎在运行或检查依赖时向应用包写入字节码，阻止原地修改发行版内置依赖。
- 应用仍未经过 Apple 公证，首次启动可能需要在「隐私与安全性」中手动允许；详见仓库中的 macOS 安装说明。
