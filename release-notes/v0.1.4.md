## Mason v0.1.4

把嘉立创 Gerber 变成可直接 3D 打印的锡膏印刷工具。本次更新带来**拼版识别**与**矩形钢网**两项能力。

### ✨ 新增

- **拼版 Gerber 双口径建模**
  导入嘉立创 / EasyEDA Pro 导出的拼版 Gerber 时，现在能正确识别整版（此前只认到一块单板）。
  - 解析器补全 `%SR` 步进重复的 `I/J` 与 `X/Y` 两种间距写法，并展开阵列
  - 轮廓提取改用含工艺边 / V-CUT 框的整版包围盒
  - 导入预览卡片显示拼版阵列（列 × 行），并弹出对话框选择口径：
    **整版（含工艺边）** 或 **单块单板**
  - 口径在参数面板顶部可随时切换，切换后自动重算钢网尺寸与唇宽

- **钢网长宽独立可调（支持矩形钢网）**
  钢网夹具的钢网尺寸由单一正方形改为 **长(X) / 宽(Y)** 两个独立输入（10~290mm，5mm 步进），可直接按实际购买的矩形钢网建模。
  - 凸台与 A/B 框窗口逐轴跟随钢网变为矩形
  - 夹具底板仍保持正方形，四角定位与螺丝布局不受影响

### 🔧 改进

- **唇宽改为单条滑块**：钢网外缘压在凸台上的唇宽（0 ~ 上限）由一条滑块控制，四边一致；读数实时显示凸台与窗口的逐轴尺寸。上限取两轴中更紧的一侧，保证凸台每轴都不小于 PCB 槽，避免 PCB 悬空。
- **旧项目文件兼容**：单值 `stencil_size` 自动映射到 X/Y 两轴；旧项目的 `platter_width` / `platter_margin` 反推为等效唇宽，老工程文件仍可正常打开。

### 🐛 修复

- **CI 几何验证长期失败**：`test_v2` 把 4 角定位柱孔径硬编码为 `r=4.7`，未跟随 v0.1.3 新增的 `post_clearance`（默认 0.4mm，实际孔径为 `corner_d/2 + 2.0 + post_clearance`）。现改为与 `jig_generator.build_base` 同源推导，几何验证恢复全绿。
- **测试用例适配新参数语义**：`test_screw_spec`（周圈孔位改为按窗口几何动态推导）、`test_notch_depth`（期望缺口深度改为 `min(10mm, 实测壁深)`）、`test_notch_stencil`（改用新 API 复现同一凸台几何）同步更新。
