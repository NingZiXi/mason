拖入 → 预览 → 导出

核心设计目标是「拖入 Gerber → 导出 STL」的极简工作流，默认参数即可产出可用结果。

TWO MODES

两种模式，覆盖原型到量产

从快速原型验证到小批量生产，选择最适合你场景的工作方式。

你打算怎样制作？

JIG MODE适合你的选择

钢网夹具模式

金属钢网夹在下方的 B 面底座与上方的 A 面顶盖之间,由周圈螺丝夹紧；夹好的组件再通过 PCB 托盘四角的定位柱定位落下。

  • 托盘四角一体定位柱,用于组件落位,不装螺丝
  • 夹紧螺丝仅布置在框体周圈,支持 M2 / M2.5 / M3
  • 夹具尺寸按钢网自动计算，同尺寸 PCB 复用
STENCIL MODE适合你的选择

PCB 钢网模式

根据锡膏层直接生成自带 PCB 卡槽的一体式钢网，独立使用无需夹具，适合快速原型。

  • 焊盘开孔与板框坐标精确对齐
  • 焊盘方形化、测试点过滤，匹配钢网厂工艺
  • 密脚错排、大孔开网格等后处理选项
FEATURES

为锡膏印刷而生的细节

自研 RS-274X 解析器 + build123d 参数化 CAD 内核，把每个环节做到开箱即用。

内置引擎零配置

发布包内嵌完整 Python 运行时，最终用户无需安装任何环境，双击即用。

FAQ

常见问题

需要什么运行环境？

发布版自带内置 Python 引擎，无需安装任何环境，下载安装即可使用。仅开发者从源码运行时才需要 Node.js 20+ / Rust 1.77+ / Python 3.11+。

支持哪些 Gerber 文件？

支持嘉立创 / JLCPCB 导出的 Gerber ZIP。板框识别依赖 .GKO / Edge.Cuts / .GM1 文件；钢网模式还需要 .GTP / .GBP 锡膏层。文件命名特殊时可在导入界面手动选择。

钢网焊盘和 PCB 焊盘对不上怎么办？

Mason 默认对长圆形焊盘做方形化处理（匹配钢网厂工艺），并按 PCB 板框居中对齐。若仍有偏差，请检查 Gerber 坐标系是否与板框层一致。

导出的文件在哪里？

导出时会在所选目录创建 mason_export_<时间戳>/ 子文件夹，所有 STL / STEP 文件放入其中，避免与现有文件混淆。
