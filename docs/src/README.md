# PCB2 网页交互讲解

首页五步讲解的原始代码：`pcb2-story.js` 管理文案、切换和播放，`pcb2-scene.js` 渲染真实模型。修改后在仓库根目录运行：

```sh
node scripts/build-site-story.mjs
```

生成文件位于 `docs/assets/story/`，随静态站点一起部署，无需 CDN。构建成功后会清理旧的场景代码分块，保留 CAD 资产。渲染代码和模型在讲解区域进入视口后加载；只有步骤过渡与装配播放期间持续绘制。加载时仅显示文字提示，预热结束并绘制当前步骤后才显示模型，不使用旧视频封面占位。模型加载失败或 WebGL 上下文丢失时显示文字提示，步骤、说明、示例下载和完整视频仍可使用。

数据来自 `films/mason-pcb2-explainer/public/` 的真实 PCB2 Gerber 解析结果及 Mason 建模引擎生成的 STL。`.bin` 文件为二进制 STL；`board.json` 保留板框、孔洞、锡膏焊盘和钢网尺寸，`mechanics.json` 提供周圈螺丝位置。示例 PCB 为 85 × 60 mm，顶层解析 347 个焊盘、底层 106 个。修改样例或建模参数时应同步重新生成这些资产。

装配顺序从上至下为 A 面顶盖、金属钢网、B 面底座、PCB 托盘。周圈螺丝先夹紧上方三层，再将整个组件沿托盘四角定位柱落下；托盘保持不动。场景坐标以毫米计，B 面底座翻转后占据高度 4–8，钢网占据 8–8.3，顶盖占据 8.3–12.3；组件从整体抬升 30 降至 0。

桌面左右布局，窄屏模型在上、说明在下。支持页签、上一步/下一步、左右方向键、Home/End 和模型区域横向滑动。开启减少动态效果时，装配不自动播放，可直接选择分解、夹紧、落位。中英文随站点语言切换。

步骤间采用 640 ms 模型位置/透明度插值与相机四元数球面插值，文字轻移淡入。相机沿目标点转动，避免接近俯视时逐帧 lookAt 引发突然转向。快速切换从当前显示姿态继续，装配在入场结束后开始。隐藏页面、离开讲解区域或展开视频会停止动作。装配按真实经过时间推进，较慢设备也不会因帧率降低而延长整个流程。

所有工具的着色器和几何数据在加载海报后预热，材质透明设置在切换期间保持稳定；重复螺丝使用实例绘制。步骤过渡复用阴影贴图并降低绘制分辨率，静止后恢复完整细节；柔和接触阴影随位置和落位进度连续变化。`node verify-story-motion.mjs` 检查首次正反向切换期间没有新增着色器编译或几何上传、相机接近俯视时没有末段转向突变，以及中途打断不会跳到上一目标；记录实际帧间隔供对比，软件渲染器结果不代表硬件帧率。

材质使用本地生成的 RoomEnvironment 棚拍反射：钢网为带方向性反射的金属，打印件为哑光；定向灯投影与柔和接触阴影共同表现落位。夹紧阶段轻微强调上方三层，定位阶段强调真实坐标处的四个定位柱，并同步更新图例、双语说明和随模型投影的细引线。所有提示动画随状态变化停止，不使用持续闪烁或后台循环。

`site-polish.js` 统一整站入场：标题、说明和内容在首次进入时按阅读顺序淡入，元素随后取消观察，不会反复隐藏。键盘聚焦和减少动态效果设置会立即展示内容；禁用脚本时正文默认可见。按钮的箭头、边框、阴影及按压反馈使用 CSS。

示例区的角标与稀疏刻度为装饰；85 mm / 60 mm 尺寸线按 Gerber 板框实际边界和当前 PCB 模型矩阵投影，仅在前两步静止时显示，过渡时淡出，移动端保持在画布内。它们使用 SVG，保留已确认的模型相机路径与渲染策略。

浏览器验证在 `films/mason-pcb2-explainer` 下运行 `node verify-story.mjs`；需本地站点运行于 `http://127.0.0.1:4173/`。检查不同屏幕宽度、双语、机械接触位置、播放控制及预览失败回退。

`node verify-site-polish.mjs` 检查入场仅出现一次、卡片与按钮反馈、动态切换减少动态效果、无脚本可读性，以及三个屏幕宽度下的投影尺寸和页面溢出；截图与报告位于 `evidence/polish/`。

`site-extras.js` 提供双语模式选择；选择方案后突出下方匹配卡片，并显示一句推荐说明。点击另一选项即可切换，不另设跳转或重置按钮。

细节查看使用全屏透明覆盖层，页面背景毛玻璃虚化，模型直接呈现在屏幕中央，不显示窗口底板或边框。原生 dialog 保留焦点管理与 Escape 退出；`detail-viewer.js` 与 OrbitControls 首次打开时加载。默认展示完整装配，另有三个细节观察点，支持拖动、滚轮/双指缩放、方向键旋转和 +/- 缩放。打开时暂停主讲解，关闭时禁用细节控制并恢复焦点，不会自动恢复主讲解；静止时不持续绘制。视角支持重置，预览失败仍可关闭并观看下方演示，重新打开可重试。手机横竖屏使用自适应布局，操作区留在屏幕内。

`node verify-site-extras.mjs` 在桌面与窄屏验证细节控制、模态焦点恢复、双语、两种模式推荐、下载与 WebGL 失败回退，截图与结果位于 `evidence/extras/`。

`docs/assets/visual-refinement.css` 为整站版式、字体及光影精修，最后加载；沿用原有绿色、纸白背景和交互，不新增功能。统一阅读宽度、页面边距、标题字重/字距、正文行高和卡片边缘光影，主展示区的阴影比辅助卡片稍深。移动端首屏保留左右边距，品牌中文不折行；功能卡片平板两列、手机单列，装饰立方体按窄屏缩小。首屏独立钢网标注移到模型下方，避免中英文文字超出 SVG 画布。

`node verify-refinement.mjs` 验证 320/390/768/1024/1440 px 下的双语布局、文本溢出、FAQ、五步模型及细节窗口；截图与报告位于 `evidence/refinement/`。

`pointer-effects.js` 与最后加载的 `pointer-effects.css` 统一鼠标跟随：首屏模型最大约 2° 偏转、5 px 平移，网格反向轻移；模式/功能卡片与工作流程区域随鼠标移动出现柔光和约 1° 的倾斜。采用按时间阻尼，稳定后停止 RAF；移开鼠标后回正。只对精确鼠标且未开启减少动态效果的设备启用，触屏、失焦、隐藏页面、偏好变更会清理。滚动时清理已经移出鼠标位置的区域，避免与浏览器滚动锚定互相触发；保留已有装配及滚动效果，替换原先独立的首屏鼠标/网格监听。

`node verify-pointer-effects.mjs` 检查跟随、阻尼停止、移出回正、失焦和滚动清理、动态切换减少动态效果及触屏禁用；截图与结果位于 `evidence/pointer/`。

最终性能检查：界面截图提供 800 / 1600 / 原尺寸的 WebP，由 `scripts/build-site-images.py` 生成，浏览器按显示宽度与像素密度选择资源；保留固定宽高，避免图片加载时跳动。首屏不加载 CAD 渲染器、模型或视频。装饰时间线、粒子与截图轮播在离开视口或页面隐藏时暂停；减少动态效果设置变化后立即生效。滚动更新合并到同一帧，先读取布局再写入样式；首屏离开后停止重复写入视差。手机讲解手势区分横向切换与纵向滚动，横屏细节窗口限制高度并允许内部滚动。

在 `films/mason-pcb2-explainer` 下运行 `node verify-final-performance.mjs`，检查首屏请求、内容位移、离屏暂停、轮播与动态偏好、手机手势、横屏弹窗和运行时错误，记录加载与滚动指标到 `evidence/final-performance/report.json`。弱网配置为 80 ms 延迟、200 KB/s 下载、4 倍 CPU 减速；滚动测量在模型加载完成后恢复正常 CPU 速度。测试使用 Chromium 软件 WebGL，帧间隔包含软件绘制与截图资源解码开销，不能作为真实手机或线上 CDN 的帧率承诺；上线后仍需结合真机和线上网络复核。
