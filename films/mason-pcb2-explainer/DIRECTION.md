# Mason / PCB2 — 从板框到装配

## 范围与选择
用户要求：用于官网的 20–30 秒讲解动效，使用提供的 PCB2 Gerber 示例，取代实操录屏。按 28 秒、1920×1080、30fps、中文字幕执行。范围是当前桌面产品的 Gerber 导入、双模式产物、夹具装配与模型导出，不讲版本更新、CLI 或移动端。

三个候选方向：A 浅色工程图与真实 CAD 匹配剪辑；B 深色微距与快速穿越；C 软件窗口驱动的操作故事。选 A：需要清楚解释机械结构；上一支 mason-live 使用深色长录屏与旁白，本片改用浅色空间、模型驱动、短句字幕与稀疏拨弦节拍，开场不再从空状态窗口开始。

## 事实与素材
源文件为用户提供的 Gerber_PCB2_2026-09-19.zip，哈希与解析结果见 evidence/source.json。生产代码 src/lib/gerber/parser.ts 与 pads.ts 直接解析，python/jig_generator.py 直接生成三件夹具和一体式钢网 STL。尺寸 85×60mm；顶层 347 个、底层 106 个解析焊盘（不是承诺最终开孔数）。性能不做宣传数字。

本片是用户指定的机械讲解动效，不模拟软件 UI。展示层调用真实 Gerber 解析器、使用真实 CAD 导出网格；使用与 ModelPreview.vue 相同的 STLLoader 渲染链。桌面业务视图依赖 Tauri invoke 与原生对话框，在离线可定位时间的影片中无法直接操作；因此不绘制伪造界面，不声称录屏。形体与数据的来源保留在工程，原桌面源码不改。

## 专属手法
- 因为输入是板框与锡膏层，先沿真实轮廓描绘，再显现真实焊盘，而非随机粒子。
- 因为有两类独立产物，用同一块板匹配剪辑到金属钢网夹具与独立打印钢网，明确材料区别。
- 因为托盘有四角一体定位柱，装配用真实透视、遮挡与 CAD 孔位说明落位，绝不把柱当螺丝。
- 因为三层先夹紧后定位，先改变子件高度，再移动共同父组；金属钢网厚 0.3mm，底座 4mm、顶盖 4mm，最后 base 4..8 / mesh 8..8.3 / cover 8.3..12.3；托盘凸台顶面 8mm。
- 因为结果可离线使用，最后让实际模型与可下载示例同时出现，不用虚构打印实物。
